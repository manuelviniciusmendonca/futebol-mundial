# Futebol Mundial

Aplicação estática em português para simular partidas, copas e ligas. A interface e os recursos seguem o arquivo HTML de referência.

## Executar localmente

Abra `index.html` em um navegador. Não há dependências, etapa de compilação ou servidor de aplicação.

## Deploy

Publique a pasta do projeto como um site estático, usando `index.html` como página inicial. Por exemplo:

- **GitHub Pages:** publique a raiz da branch configurada nas definições do repositório.
- **Netlify ou Cloudflare Pages:** conecte o repositório e deixe em branco os comandos de build; use a raiz do projeto como diretório de publicação.
- **Outro host estático:** envie `index.html` (e este README, se desejado) para a raiz do site.

Não são necessárias variáveis de ambiente, credenciais ou serviços externos. Como não há processo de build, não configure comando de build nem diretório `dist`.
